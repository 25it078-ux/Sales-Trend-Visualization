# Sales Trend Visualization
## Objective
Analyze and visualize monthly sales data to identify sales trends over time.
## Tools Used
* Python
* Pandas
* Matplotlib
## Project Description
This project visualizes monthly sales data using a line chart. The chart helps identify growth patterns and sales performance throughout the year.
## Output
A line chart showing monthly sales trends from January to December.
